Calculadora de Alicia para dividir: 4 ejemplos resueltos

La división larga es la operación que más dudas genera en primaria. Estos cuatro ejemplos van de menor a mayor dificultad. Intenta resolver cada uno antes de leer la solución y luego compruébalo con la calculadora de Alicia para dividir, que muestra el mismo procedimiento.

Ejemplo 1: divisor de una cifra (936 ÷ 4)

9 ÷ 4 = 2, 2×4 = 8, resto 1
Bajo el 3 → 13 ÷ 4 = 3, 3×4 = 12, resto 1
Bajo el 6 → 16 ÷ 4 = 4, 4×4 = 16, resto 0
Cociente 234, resto 0

Ejemplo 2: divisor de dos cifras (1872 ÷ 24)

18 no alcanza para 24 → tomo 187
187 ÷ 24 = 7, 7×24 = 168, resto 19
Bajo el 2 → 192 ÷ 24 = 8, 8×24 = 192, resto 0
Cociente 78, resto 0

Truco: para estimar cuántas veces cabe 24, piensa cuántas veces cabe 2 en 18. Si te pasas, baja una unidad.

Ejemplo 3: un cero en el cociente (6135 ÷ 3)

6 ÷ 3 = 2, resto 0
Bajo el 1 → 1 ÷ 3 = 0 → ¡escribo 0 en el cociente!
Bajo el 3 → 13 ÷ 3 = 4, resto 1
Bajo el 5 → 15 ÷ 3 = 5, resto 0
Cociente 2045, resto 0

Este es el error más común: olvidar el 0 y escribir 245.

Ejemplo 4: división con decimales (7 ÷ 8)

7 no alcanza para 8 → cociente 0, pongo la coma
70 ÷ 8 = 8, resto 6
60 ÷ 8 = 7, resto 4
40 ÷ 8 = 5, resto 0
Cociente 0,875

Cómo comprobar cualquier división

Multiplica el divisor por el cociente y suma el resto. Si obtienes el dividendo, la división está bien. Por ejemplo: 24 × 78 + 0 = 1872.
